寂静岭同人 · 雾中回响  (Silent Hill Fan Demo — Echoes in the Fog)  v1.2
================================================================
非官方同人作品 · 与 KONAMI 无关 · 仅供学习交流，请勿商用。
「寂静岭 / Silent Hill」为 KONAMI 的注册商标。本作未使用任何原作美术、音乐或音效素材。

【如何运行】
1. 解压整个文件夹（不要在压缩包里直接运行）。
2. 双击 SH_FogEcho.exe。
3. 如果出现黑屏、闪退或提示 Vulkan 错误（老显卡 / 核显较常见），
   请改为双击 Compatibility_Mode_OpenGL.bat（OpenGL 兼容模式，画质较低、无体积雾）。
4. 卡顿时：Esc → 设置 → 画质 选「低」，渲染分辨率选 75% 或 50%。

推荐配置：Windows 10/11 64 位，支持 Vulkan 的独立显卡（GTX 1050 / RX 560 及以上）。
建议戴耳机，在关灯的房间里游玩。流程约 40～60 分钟。
注：v1.2 使用新的存档文件，不会读取 v1.1 的进度。

【操作】（游戏内 Esc → 操作说明 可随时查看）
WASD 移动　　Shift 奔跑（消耗体力）　　鼠标 环顾　　F 手电筒
E 调查 / 拾取 / 阅读 / 与商人交易
鼠标左键 攻击 / 射击（倒地的敌人：靠近再按左键＝踩踏）
鼠标右键 举枪瞄准（步枪会打开瞄准镜）　　R 换弹
1 钢管　2 手枪　3 步枪（或鼠标滚轮切换）
Space 闪避（闪避瞬间无敌；在敌人攻击命中前一刻闪避＝“完美闪避”，短暂子弹时间）
Q 推开（消耗体力；在敌人扬手出招的瞬间推＝“反击”，可直接把它推倒）
H 快速回复（自动使用一件回复道具）　　Tab 物品栏　　M 地图　　T 收音机开关　　Esc 暂停 / 设置
手柄：左摇杆移动，右摇杆视角，A 调查，RT 攻击，LT 瞄准，X 换弹，B 闪避，RB 推开，
　　　Y 手电筒，十字键 ←/→ 切换武器，Start 暂停。

【武器 · 搜刮 · 金币 · 商人】
· 钢管：不耗弹药，可以踩踏倒地的敌人。手枪：精准、可爆头。步枪：带瞄准镜，威力极大，子弹可穿透。
· 瞄准时准星会逐渐收拢——站稳、等准星收紧再开枪更准；移动/奔跑会让准星散开。
· 抽屉、柜子、箱子等发光提示“搜查”的地方可以搜刮：子弹、回复道具或金币。
· 击倒敌人会掉落金币，靠近即可自动吸取。
· 提着昏黄提灯、裹着斗篷的商人会出现在特定地点（咖啡馆、学校教师休息室），
  可用金币购买子弹、健康饮料、急救包，甚至枪械。

【敌人】
· 血肉人形：会追击、喷吐腐蚀酸液、装死伏击；被打倒后还会爬起来——一定要补上几脚。
· 匍匐者：贴地爬行，在黑暗里很难发现。
· 乌鸦：成群栖息，受惊后盘旋、俯冲啄击；单只很脆弱。
· 恶犬：速度快，会绕圈、扑咬，有的正埋头啃食……
· 锅炉房深处还潜伏着什么巨大的东西。

【章节与谜题】（无剧透）
序章　雾中小镇：追随女儿的身影，找到咖啡馆与警车。
第一章　霍华德家（Levin 街）：校工霍华德的屋子。留意屋里的照片——抽屉密码锁就藏在其中。
第二章　米德维奇小学：门厅、走廊、教室、音乐教室、医务室、教师休息室、校长室……
　　　· 门厅的老座钟：公告栏和墙上的涂鸦会告诉你时间。
　　　· 校长室的电子门锁：四位密码分散在四个房间的黑板与墙上（①②③④）。
终章　锅炉房：一切的源头。

【提示】
· 收音机的杂音越响，怪物就越近。奔跑、开枪和手电筒都会让你更容易被发现。
· 子弹有限，钢管 + 推开 + 踩踏可以省下很多子弹。
· 地图上的红色标记会提示下一步去哪里。
· 游戏会在关键地点自动记录进度（画面右下角提示），死亡后可从最近的记录点重来。
  存档位置：%APPDATA%\SH_FogEcho\

【故事】
那天夜里，你开车带着女儿「小雪」前往寂静岭度假。车灯里突然闪过一个人影——
醒来时，车撞在路边，四周全是浓雾，副驾驶座上空无一人……
小雪留下的画、警车里的便条、校工霍华德的日记，
一点点把你引向雾中那所早已停课的小学，和它地下那间烧了很多年的锅炉房。
