# 寂静岭同人 Demo「雾中回响」— 开发计划（内部）
Godot 4.3, Forward+（Vulkan/D3D12）主渲染；提供 Compatibility 低配启动 .bat。第一人称。
渲染：SubViewport 低分辨率(默认1/2) + 后处理(颗粒/暗角/色调/色差/静电噪点) + 体积雾。
关卡：ASCII 网格(2m/格) -> 程序化几何（墙/窗/门/地面/悬崖），AStarGrid2D 给怪物寻路。
表里世界：surface 着色器 ow_mix(0雾世界→1里世界) 噪声溶解+燃烧边缘；里世界=锈铁/铁网地板/血迹/黑雾/红灯。
流程：车祸醒来→追女孩身影→咖啡馆(收音机/地图/钢管/饮料/便条)→出门遇怪→小巷→公园(女孩的画:去学校)
→学校大门锁(便条:钥匙在狗屋)→Levin街后院狗屋拿钥匙→警报→里世界→回学校开门→结局。
素材：Poly Haven/ambientCG 贴图(CC0)，Kenney 车/家具/音效(CC0)，Freesound CC0(警报/杂音/工业环境)，其余程序合成。
字体：Noto Serif CJK SC(OFL)，霞鹜文楷(OFL) 子集化。
