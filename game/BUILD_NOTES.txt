雾中回响 · 工程源码说明（v1.1）
========================
1. 安装 Godot 4.3 stable（标准版，非 .NET）：https://godotengine.org/download/archive/4.3-stable/
2. 打开 Godot → 导入 → 选择本文件夹中的 project.godot。首次打开会自动导入资源（约 1～3 分钟）。
3. 按 F5 运行（主场景 main.tscn）。
4. 导出：编辑器菜单 项目 → 导出，已预设 "Windows Desktop" 与 "Linux"（需先安装 4.3 导出模板）。

目录结构
· scripts/  全部游戏逻辑（GDScript）
    main.gd    流程 / 剧情 / 环境雾 / 表世界↔里世界切换 / 存档点 / 怪物刷新（含伏击尸体、雾中人影）
    world.gd   程序化生成小镇（街道、建筑、小巷、咖啡馆、学校、后院）
    player.gd  第一人称移动、体力、手电筒、钢管攻击、酸液灼伤
    monster.gd 怪物：骨骼程序动画（瘸腿拖行、断颈乱颤、痉挛、裂口张合、皮下蠕动、爬行、倒地抽搐）
               + AI（游荡 / 追击冲刺 / 喷酸 / 倒地踩踏 / 装死伏击 / 雾中人影）
    acid.gd    怪物喷出的酸液投射物与地面酸池
    girl.gd    女孩剪影与引导
    ui.gd      标题、字幕、物品栏、地图、设置、暂停与死亡画面
    game.gd    全局状态、设置、存档读写（自动加载）
· shaders/  路面/墙面材质、血肉（flesh2.gdshader：三平面采样+顶点蠕动+伤口/血管/淤青）、车漆、全屏后处理
· assets/   CC0 贴图、模型、音效与合成音乐、字体子集
    assets/models/monster.res  怪物网格+蒙皮，由 tools/sculpt_monster.py 雕刻生成，再经 dev/build_monster.gd 转为 Godot 资源
· tools/    生成素材所用的 Python 脚本
    sculpt_monster.py   程序化雕刻怪物（SDF 体素 → 网格 → 骨骼权重）
    gen_flesh_tex.py    怪物皮肤/污垢贴图
    gen_monster_audio.py 怪物音效（基于 CC0 录音加工，来源见 fs2_credits.json）
    gen_audio.py / fs_*.py 环境音效与音乐；build_fonts.py 字体子集；其余为贴图/地图生成
· dev/      开发用自动测试与截图场景（不会被导出）：
    test_flow.tscn  全流程自动通关测试    test_death.tscn 死亡/重试/读档测试
    test_walk.tscn  全路线碰撞行走测试    test_mon.tscn   怪物行为测试（人影/喷酸/伏击）
    shot_main.tscn  批量截图              mon_preview.tscn 怪物多角度近景预览

注意：fonts 为按游戏文本裁剪的子集；如新增中文文本，请运行 tools/build_fonts.py 重新生成
（需要 fonttools 与 Noto Serif CJK / 霞鹜文楷原始字体）。
